Entry for the [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on make.fun.

**appnesia — opening an app and forgetting why you opened it.**

`main.py` (pure Python standard library, deterministic) writes that one line to `/output/entry.txt`. Nothing else to build, nothing to run — the word and its definition are the whole entry.

## Run

```sh
python3 main.py
```
